# 포켓 아케이드 (Pocket Arcade)

모바일 우선으로 만든 오프라인 미니게임 모음입니다. 외부 라이브러리 없이 순수 HTML/CSS/JS로 만들었습니다.

- **오프라인 플레이**: 한 번 접속한 뒤 "홈 화면에 추가"하면 인터넷 없이 실행됩니다 (PWA / Service Worker).
- **저장**: 기기 브라우저의 localStorage에 저장합니다. 서버나 DB가 필요 없습니다. 설정 화면의 "저장 백업/불러오기"로 다른 기기에 옮길 수 있습니다.
- **조작**: 모바일은 가상 방향키 또는 화면 드래그, PC는 방향키/WASD.

- **내 캐릭터 + 육성**: 처음 실행 시 캐릭터(성별/피부/머리/옷/아이템)를 만들고, 미니게임 점수로 경험치를 얻어 레벨업합니다. 레벨에 따라 아이템·색상이 해금됩니다.
- **개발자 화면**: 메인 로고를 5번 연속 탭 → 비밀번호 입력. 패치 이력, 앱 정보, 저장 데이터, 강제 업데이트 등.

## 파일 구조
| 파일 | 내용 |
|---|---|
| `js/version.js` | 앱 버전, 패치 이력 (업데이트 시 여기에 기록) |
| `js/avatar.js` | 캐릭터 도트, 꾸미기 옵션, 해금 레벨 |
| `js/core.js` | 저장, 육성, 입력, 화면 전환, 게임 루프 |
| `js/dev.js` | 개발자 화면 |
| `js/games/dungeon.js` | 던전 탈출 |

## 새 미니게임 추가하기
1. `js/games/새게임.js` 파일을 만들고 `Arcade.register({ id, title, desc, drawIcon, create })`로 등록
   - `create(api)`에서 `api.profile()`(캐릭터), `api.addXp(n)`(경험치 지급) 사용 가능
2. `index.html`에 `<script>` 추가
3. `sw.js`의 `ASSETS` 목록에 파일 경로 추가하고 `CACHE` 이름의 숫자를 올림
4. `js/version.js`에 버전과 패치 내용 기록

## 개발자 비밀번호 바꾸기
```
node tools/dev-password.js 새비밀번호
```
출력된 값을 `js/dev.js`의 `DEV_HASH`에 넣습니다. 코드가 공개되어 있으므로 일반 사용자에게 숨기는 용도로만 쓰세요.
